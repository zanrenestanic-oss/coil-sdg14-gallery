# MANJ, A BOLJE — interaktivna galerija SDG 14

Spletna galerija za šolski projekt o 14. cilju trajnostnega razvoja: življenje pod vodo.

## Datoteke
- `index.html` — struktura in besedilo strani
- `style.css` — celoten odzivni dizajn
- `script.js` — filtri galerije, povečan prikaz fotografij, 7-dnevni izziv in kviz
- `images/dijakA/` in `images/dijakB/` — mapi za vajine lastne fotografije
- `videos/` — mapa za manjše videe; večje videe je bolje vdelati s povezavo

## Pred objavo
1. Zamenjajta vzorčne fotografije z najmanj 6 lastnimi fotografijami na osebo. V `index.html` zamenjajta naslove slik (`src` in `data-image`) ter ustrezne opise.
2. V razdelku »O projektu« dodajta svoja imena in videoposnetka. Za YouTube uporabita vdelavo (`iframe`) ali povezavo do videa.
3. Preverita besedilo, delovanje filtrov, kviza in izziva na telefonu ter računalniku.
4. V GitHub repozitoriju odprite **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Predlagana razdelitev dela
- **Dijak A:** uvod v SDG 14, vsaj 6 lastnih fotografij, naslovnica in prvi del galerije, svoj video.
- **Dijak B:** opis izbrane težave, vsaj 6 lastnih fotografij, drugi del galerije in zaključek, svoj video.
- **Skupaj:** načrtovanje, interaktivnost, testiranje, GitHub Pages in končna predstavitev.

Fotografije na strani so vzorčne zunanje slike. Za končno oddajo uporabita lastne fotografije in poskrbita za dovoljenja za vse druge uporabljene vsebine.
